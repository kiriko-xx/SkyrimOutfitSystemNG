1.5.43: fix the golden items page (row hit boxes, manual save, light plugin ids)

- group rows and the plugin picker use an explicit row size (GoldenRow) and the
  two columns are clamped, so the list can be clicked and the editor no longer
  covers it; selecting a group logs 'Menu: golden group <name> selected.'
- the editor only marks itself dirty (g_goldenDirty): the Export button is the
  only thing that writes OutfitSystemGoldenItems.json, and the page shows a
  [not saved] hint until then. Changes still take effect in memory at once.
- golden item ids are stored with the width the plugin needs (12 bits for light
  files, 24 bits otherwise). The old 24 bit value of a light plugin carried the
  run-time light index, and TESDataHandler::GetFormID does not mask it, so
  LookupForm stacked the index twice and every entry was missing. New helpers
  PluginScan::IsLightPlugin / LocalIdFor / ResolveForm normalise on load, so the
  61 entries of an existing file are repaired automatically.

Engine side (hooks, attachment, slot cleanup, .tri, scene outfits) untouched.
